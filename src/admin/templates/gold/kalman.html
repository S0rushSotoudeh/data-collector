Methodology and data quality


All controls and charts display Asia/Tehran time including seconds. Stored instants carry a timezone. Ranges are [from,to): the end is excluded. Session boundaries and warm-up can explain why a run has no earlier score. Navigation reads saved outputs; it never runs the filter backward.


Source quote time dates the source state. Availability time is when that state was usable. Decision time is the replay clock. Quote age = decision − source time; delivery delay = availability − source time. A fresh cached book may score but is not assimilated again. Unknown phase, auctions, halts, invalid books and stale quotes suppress scores.


Synchronized synthetic fixtures can correctly have all-zero quote ages. For real sources, inspect clock conventions when all ages are zero. Missing timestamps are unavailable, never zero-filled.


Calculation guide and worked example

Midpoint = (ask + bid)/2. Imbalance = (bid quantity − ask quantity)/(bid quantity + ask quantity). Microprice = (ask × bid quantity + bid × ask quantity)/(bid quantity + ask quantity).


Example, not market data: bid 100, ask 102, bid size 300 and ask size 100 gives midpoint 101, imbalance 0.5 and microprice 101.5. If the independently calculated fair price is 102, deviation is −49.020 bps, cheap edge 0 bps and rich edge −196.078 bps. A 12:00:02 source quote at 12:00:05 is three seconds old. Z additionally needs the actual calibration and excluded benchmark variance.


Kalman scores use log microprice minus calibrated offset alpha, with inverse noise-variance weights. Process variance q is derived from factor memory half-life; r comes from robust normalized peer-residual scale. The inspector shows the pre-update prior and current-batch exclusion. Older observations of the focal ETF remain in the prior; this is not full historical leave-one-out. The factor chart shows the post-update factor.


Session-calibrated refits using authorized preceding sessions. Frozen holds the initial fit but updates its state. Peer median uses contemporaneous normalized peers with the same modeled normalization. No method estimates NAV. Original outcome peers are frozen; future data never repair missing endpoints.
